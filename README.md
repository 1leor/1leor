## National Digital Twin Programme

### Platform & Governance

- [ndtp-ai-ontology-extension](https://github.com/National-Digital-Twin)  
  AI-assisted ontology generation and extension tooling for semantic data models and digital twin ecosystems.

- [ndt-data-catalogue](https://github.com/National-Digital-Twin/ndt-data-cprise) data catalogue based on DataHub for discovery, governance and management of data assets.

- [ndt-overwatch](https://github.com/National-Digital-Twin)  
  Central automation platform used to run organisation-wide workflows and operational processes.

- [ospo-resources](https://github.com/National-Digital-Twin/ospo-resn) Source Programme Office resources, guidance and reusable tooling.

- [archetypes](https://github.com/National-Digital-Twin)  
  Repository templates and starter structures for creating new projects.

### Integration Architecture

- [dpn-integration-playbook](https://github.com/National-Digital-Twin)  
  Deployment and configuration guide for Data Preparation Nodes within the Integration Architecture.

- [DSI-Diagrams](https://github.com/National-Digital-Twin)  
  Architecture and infrastructure diagrams describing NDTP data-sharing patterns and components.

### User Experience

- [ndtp-styling-assets](https://github.com/National-Digital-Twin/ndtp-Shared) SCSS styling framework used across NDTP web applications.

- [ndtp-component-library](https://github.com/National-Digital-Twin)  
  Reusable front-end components for building consistent NDTP applications.

### Digital Twin Applications

- [VISTA](https://github.com/National-Digital-Twin)  
  Asset resilience and situational awareness platform for analysing critical infrastructure and regional impacts.

- [IRIS](https://github.com/National-Digital-Twin)  
  Housing retrofit and energy-efficiency decision-support platform driven by property and performance data.

- [NOVA](https://github.com/National-Digital-Twin)  
  Geospatial planning tool for renewable energy, infrastructure and location-based scenario modelling.

- [LISA](https://github.com/National-Digital-Twin)  
  Multi-agency incident coordination platform supporting information sharing during emergencies.

## National Node Net

### Secure Data Sharing Infrastructure

- [secure-agent-graph](https://github.com/National-Node-Net/secure-agent-graph)  
  Knowledge graph platform providing GraphQL access, Kafka integration and policy-based data sharing.

- [rdf-abac](https://github.com/National-Node-Net/rdf-abac)  
  RDF and Apache Jena extension implementing Attribute-Based Access Control (ABAC).

- [rdf-pbac](https://github.com/National-Node-Net/rdf-pbac) implementation for fine-grained control of shared data.

- [graphql-jena](https://github.com/National-Nodena)  
  Apache Jena plugin enabling GraphQL access to RDF and knowledge graph data.

- [ianode-access](https://github.com/National-Node-Net/ianodetity) and attribute service used to support access-control decisions.

### Data Processing & Pipelines

- [node-lib](https://github.com/Ne-Net/node-lib)  
  Python framework for building modular data ingestion and transformation pipelines.

- [secure-agents-lib](https://github.com/National-Node-Net/secure-agbrary) for building secure data-ingestion workflows.

- [label-builder](https://github.com/National-Node-Net/label-builder)  
data and classification engine for assigning labels to data.

- [data-extractor](https://github.-Net/data-extractor)  
  Utility for extracting data from Integration Architecture nodes into downstream storage platforms.

- [jena-fuseki-kafka](https://github.com/Nationali-kafka)  
  Apache Jena integration for ingesting data streams from Kafka.

- [fuseki-yaml-config](https://github.com/National-Node-Net/f) Tooling for generating Fuseki configuration from YAML definitions.

### Security & Federation

- [jwt-servlet-auth](https://github.comjwt-servlet-auth)  
  JWT authentication framework used across secure data-sharing services.

- [federator-certificate-manager](https://github-certificate-manager)  
  Automated certificate lifecycle management for trusted federated communications.
